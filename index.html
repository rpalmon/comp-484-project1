My interest: 3D Printing

From Idea to Physical Object

I like 3D Printing because it allows me to bring ideas I have to real life. It even if I am not creative, I can still find design files from online I can download and print those instead. 3D Printing also allows me to fix any problems I have with tidyness or organization by printing out specialized holders and organizers. Another bonus is that I can print out fun objects that serve no real purpose, but look cool or are just neat to have.
Another fun part about 3D Printing can be assembling the printer itself, which can be a fun project and learning experience. The best part about assembling is that if there are any problems with the printer, you would know where the problem is and how to fix it.
