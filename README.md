## Elements
- `<code>`: used in `materials.html`
  - Uses: Used to describe the printing temperatures of materials
- `<address>`: used in the footers of each page
  - Uses: used to mark the address
- `<meter>`: used in `materials.html`
  - Uses: used to describe difficulty of materials

## Attributes
- `readonly`: used in `index.html`
  - Uses: used in the form for an uneditable text input
- `autocomplete`: used in `index.html`
  - Uses: used in the form to enable browser autofill
- `capture`: used in `index.html`
  - Uses: used in the form's file input to allow for a prompt on mobile to use the device camera to take a photo
